TODAY'S CHECK 전면 개조 — 목업 v2

v2 · UI/UX 재점검 v1 피드백을 반영했습니다. v1은 그대로 보존되어 있습니다.

  • 이름 확정: TODAY'S CHECK (자간을 좁혀 워드마크로 고정, 이름 후보 비교는 제거)
  • 제목 옆에 오늘 날짜·요일 표시 부활 (01 참고)
  • 화면 가득 채우던 목록을 01처럼 둥근 사각형 카드로 감싸고, 왼쪽에 얇은 액센트 스파인을 넣어 장부/인덱스 느낌을 보강
  • 리스트별 탭의 인덱스 탭을 카드 위에 물리적으로 맞붙게 재구성 (폴더 탭처럼)
  • 자동 저장 및 "자동 저장됨 HH:MM" 표시 부활 (01 참고, 화면 하단 공통 위치)
  • 오늘 탭·리스트별 탭에 완료도 게이지 바 추가 (01의 진행률 바 참고)
  • 완료 항목 숨기기 토글 추가 — 삭제가 아니라 화면에서만 숨김. 기존 "완료 항목 삭제"는 유지하되 아래 ⋯ 메뉴로 이동
  • 다크/라이트 전환 버튼을 동기화 아이콘 왼쪽에 신설 (아이콘은 지금 모드에 따라 해/달로 바뀜)
  • UX 정리: 정렬은 마감 임박순 자동 적용이라 버튼 제거, 전체 해제·완료 삭제·리스트 삭제·이름 변경은 카드 우측 상단 ⋯ 메뉴로 모음, 로컬 백업(내보내기·가져오기)은 동기화 팝오버 안으로 통합 → 화면에 상시 노출되는 버튼 수를 줄였습니다
