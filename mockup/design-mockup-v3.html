TODAY'S CHECK 전면 개조 — 목업 v3

v3 · 접근성 검증 + 인터랙션 보강 웹 리서치와 실측 대비율 계산을 바탕으로 v2를 다듬었습니다. v1·v2는 그대로 보존되어 있습니다.

  • 명암 대비 실측 후 수정 — 라이트 모드에서 회색 보조 텍스트·오늘/기한초과 배지 글자가 WCAG AA(4.5:1) 기준에 못 미치는 걸 계산으로 확인해서 색을 더 짙게 조정했습니다 (아래 표)
  • 탭 대상 크기 — WCAG 2.5.8은 24×24px을 최소로 요구하고 애플은 44px을 권장합니다. 체크박스·별 아이콘의 보이는 크기는 그대로 두되 (장부 느낌에 맞게 작게), 실제 터치 가능 영역만 투명하게 32~36px로 넓혔습니다 (화면상 보이지 않는 변경이라 목업엔 표시 안 됨)
  • 새 리스트 만들기 흐름 — 인덱스 탭의 "＋"를 누르면 탭 자리에 그대로 입력창이 열리는 인라인 방식으로. 01의 사이드바 리스트 추가 방식과 동일한 원리입니다
  • 하위 항목 추가 흐름 — 펼친 항목의 하위 체크리스트 맨 아래 "＋ 하위 항목 추가" 줄 신설. 상단 할 일 추가창과 같은 패턴이라 따로 배우지 않아도 됩니다
  • 색상만으로 상태를 구분하지 않도록 재확인 — 토글은 칠해짐/윤곽선으로, 배지는 색+텍스트(오늘/날짜)로 이미 이중 구분되어 있어 별도 수정 없이 통과
